## EPUB 章节划分 bug 修复（EpubReader.tsx）

### 数据存储架构（分析结论）
- **Prisma + SQLite**：库文件 `data/app.db`（docker 挂载 `/app/data`），模型见 `prisma/schema.prisma`
  - `Book`：元数据（title/author/format/coverPath/filePath/fileSize），filePath 是相对 `data/uploads/` 的路径
  - `Comic`/`ComicPage`：漫画元数据 + 逐页路径；`Post`：博客；`Game`：游戏
- **文件落盘**：`data/uploads/{books,books/covers,comics,comics/covers}`，文件名 `{id}-{uuid}{ext}`，写入前 create 再 update 回填路径
- **文件服务**：`/api/files/[...path]` 受控读取（resolveSafe 防目录穿越，ETag 304 缓存）
- **阅读进度**：浏览器 localStorage，key = `mbw:book:{id}`，值为 epub.js CFI

### Bug 1：目录缺章（根因 + 修复）
- 根因：epub.js `nav.toc` 是树，epubBuilder/calibre 制作的 EPUB 把章节挂在「卷/书名」navPoint 的 `subitems` 下。测试书《宿命之环》顶层只有 2 项（封面、书名页），1179 个章节全在第二层，旧代码只 map 顶层 → 目录只剩 2 项
- 修复：`EpubReader.tsx` 增加 `flattenToc()` 递归展开 + `depth` 缩进渲染。验证：目录 2 项 → 1189 项

### Bug 2：点击目录不跳转 / 章节不动（根因 + 修复）
- 根因：React 19 + Next dev StrictMode 双执行 effect，而 effect 内 `await import("epubjs")` 期间 cleanup 已运行，闭包里 rendition/book 还是 undefined → destroy 置空跑 → 第一个实例成"僵尸"，占住可视区；第二个（真）实例的容器被挤到下方被 overflow-hidden 裁掉。点击 display 其实成功，只是渲染在被裁的容器里
- 修复：在 `await import` 之后、创建实例之前 `if (cancelled) return;`。验证：epub-container 数量 2 → 1，点击第五十章 1.5s 内正确显示
- 排查技巧：epub.js 的 `spine.get()` 匹配不到 href 时静默返回 index 0（不报错）；两个 iframe/容器堆叠 = 双实例

### Bug 3：进度永远显示"已读 0%"（根因 + 修复）
- 根因：epub.js `located()` 里 `locationFromCfi()` 在位置索引未生成时返回 -1，`percentageFromLocation()` 因 `total=0` 恒返回 0 → 每次 relocated 事件都带 percentage=0；而 `locations.generate(1200)` 对 1189 章的书要逐章解析、耗时数分钟（还可能挤爆渲染进程），索引永远"在路上" → 底栏永远 0%
- 修复（EpubReader.tsx）：
  1. relocated 处理器：索引未就绪时改用 spine 进度估算 `start.index / spine.length`（atEnd 时置 1），瞬时可得、随章节递增
  2. `locations.generate` 加规模门槛：spine > 400 章的书直接跳过生成，避免长时间 CPU/内存占用
- 验证：大书跳第五十章 → 已读 4%（约 48/1189）；小书（2 章）索引生成后精确百分比正常
- 已知权衡：大书在章节内翻页时百分比保持不变（章节粒度估算），跨章才会跳变

### 目录侧边栏增强：打开自动定位当前章节
- EpubReader.tsx：目录项加载时用 `book.spine.get(href)` 颐解析每项的 spineIndex（href→spine 序号，hash 查表很快）
- relocated 事件把 `start.index` 存入 curIndex state；activeTocIdx = 目录顺序中 spineIndex ≤ curIndex 的最后一个条目（卷首页/过渡页自然归到最近的上一章）
- 打开抽屉时 rAF 后 scrollIntoView({block:"center"})，当前项高亮（bg-ink-3/70 + text-lamp-2）；键盘翻页时抽屉内高亮实时跟随
- 验证：跳第五十章重开目录 → scrollTop=1650、目标项精确居中(offset 0)；换第八章后定位跟随

### 新增滚动阅读模式（EpubReader.tsx）
- 顶栏新增"滚动/翻页"切换按钮；偏好存 localStorage `mbw:reader-mode`（全局，跨书）
- 滚动模式：`renderTo({ manager: "continuous", flow: "scrolled-continuous" })`，垂直无限滚动、按需加载上下章节

- 滚动模式下方向键 ArrowUp/Down 映射 rendition.prev/next（continuous 管理器 = 精确滚一屏）；滚轮走浏览器原生跨 iframe scroll chaining（epub.js 不处理 iframe wheel）
- 大书进度显示改进：spine>400 章的书底栏显示 `第 X / 1189 章`（每章≈0.08%，百分比几乎不动；章节计数跨章必变）；小书仍用百分比
- 验证：垂直布局 ✓、滚轮/方向键 ✓、跨章计数更新 ✓、CFI 随滚动保存 ✓、刷新偏好+位置恢复 ✓、来回切换位置一致 ✓
